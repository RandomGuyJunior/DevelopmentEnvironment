# Underwater Advanced Fusion

Development mutator adding one underwater Advanced Fusion Reactor per faction:

- `armuwafus`
- `coruwafus`
- `leguwafus`

Design rule: each underwater AFUS keeps the corresponding land AFUS footprint, cost, production, health and build time. The gameplay difference is placement: these variants require underwater placement.

The three S3O model files are generated from the official BAR land AFUS models, preserving the original faction model, textures, piece hierarchy and COB compatibility.
